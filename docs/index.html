Why dev-box?

🎯 IDE-Independent

No vendor lock-in. Use Neovim, VS Code, JetBrains, Zed, Emacs, or plain terminal. Your choice.

🔑 Keyless SSH

Embedded SSH server. Zero keys generated. Zero setup required. Works with any SSH client.

⚡ Native Speed

Scratchpad Sync delivers 5-10x faster builds on macOS and Windows. Compile in native ext4.

🖥️ Cross-Platform

Single devbox.ini config works on Linux, macOS, and Windows. No OS-specific branching.

🧩 Layered Config

System → personal → project → local overrides. No Git conflicts. No fighting over shared config.

📦 Zero Bloat

Single 2MB Rust binary. Doesn't reinvent container runtimes. Built on Distrobox.

Quick Start

1. Install

# Via cargo (for Rust developers) cargo install dev-box # Or download pre-built binary from # https://github.com/srikanthrayudu/dev-box/releases

2. Create Config

cat > devbox.ini << 'EOF' [dev-environment] name="my-dev" image="ubuntu:24.04" additional_packages="git curl build-essential" EOF

3. Boot Environment

dev-box up

4. Connect from Your IDE

# Plain SSH ssh my-dev # Or use VS Code Remote-SSH, JetBrains Gateway, etc.

✅ No SSH keys generated. No setup inside the box. Works on Linux, macOS, Windows.
